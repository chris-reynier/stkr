# STKR user guide

STKR is a local-first task stack manager. These pages explain how to use it. If you are new, read Install, Getting started, Time tracking and Web UI first.

- [Install](install.md): download, unpack and run a release.
- [Portable](portable.md): build a no-installer copy on your own PC (no SmartScreen prompt) and set it up by hand.
- [Getting started](getting-started.md): build, run, and find your data.
- [Update](update.md): check for and install new versions.
- [Time tracking](time-tracking.md): switch contexts, read your day and week, confirm idle blocks.
- [Contexts](contexts.md): create, change, park and activate contexts.
- [Server](server.md): run `stkr serve`, autostart on Windows, port.
- [Desktop app](desktop.md): the Windows notification-area icon (`stkrw.exe`): status at a glance, an always-on-top panel with the daily actions and a hotkey, and a full app window.
- [Web UI](web-ui.md): Today, Week, Agents, Ideas, Links and Settings pages, edit your timeline, export Tempo CSV.
- [Stream Deck](stream-deck.md): switch contexts from keys and show the current context.
- [Daily loop](daily-loop.md): Start Day, Close Day, import the AI answer, project log files, reminders.
- [Agents](agents.md): see all coding agent windows, jump to the one that needs you.
- [Capture](capture.md): ideas, voice notes, phone inbox, meeting actions and decisions.
- [Bookmarks](bookmarks.md): save and find links.
- [AI providers](ai-providers.md): optional cleanup of ideas with Ollama, Claude Code or GitHub Copilot.
- [MCP server](mcp.md): let Claude Code or GitHub Copilot read and update STKR.
- [Backup and restore](backup-restore.md): backups and how to restore one.
- [Legacy import](legacy-import.md): keep a copy of data from the earlier Python version.
- [Configuration](configuration.md): every setting and its default.
- [Troubleshooting](troubleshooting.md): common problems.
- [Command reference](cli/stkr.md): every command and flag.
