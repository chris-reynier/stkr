## stkr ai run-once

Sort pending ideas now

### Synopsis

Runs one AI batch: up to 20 pending ideas get a cleaned text, a title and a suggested project. Raw text is never changed. Personal ideas are skipped unless the provider runs on this computer.

```
stkr ai run-once [flags]
```

### Examples

```
  stkr ai run-once
```
