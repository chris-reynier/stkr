## stkr ideas

List captured ideas

### Synopsis

List ideas, newest first. Filter with --status (new, triaged, done, archived) and --tag (pro, personal).

```
stkr ideas [flags]
```

### Examples

```
  stkr ideas
  stkr ideas --status new --tag pro --json
```

### Options

```
  -h, --help            help for ideas
      --status string   only ideas with this status
      --tag string      only ideas with this tag (pro or personal)
```
